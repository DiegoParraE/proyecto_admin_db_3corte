1. Para qué sirve

El programa lleva los carros, los clientes, las ventas y el taller del concesionario. Hay tres sedes: Bogotá, Medellín y Cali. Cada carro tiene un chasis. Ese número no se puede repetir. Cuando se vende, el carro queda en estado Vendido y no se puede vender otra vez.

2. Cómo prenderlo

Primero hay que abrir Docker Desktop y esperar a que quede en marcha. Después, en la terminal:

cd /Users/diego_parra/Desarrollos/proyecto_admin_db_3corte
docker compose up --build

Cuando termine de cargar, se abre el navegador en http://localhost:8080.

Este proyecto no se prende con npm ni con yarn. El comando es el de arriba.

Para apagarlo, en esa misma terminal se pulsa Control + C. Si se quiere borrar los datos y empezar de cero, el comando es docker compose down -v. Sin el -v los datos se quedan.

3. Usuarios

En el ingreso hay tres tarjetas. Si se pulsa una, se llenan el usuario y la clave. Después se pulsa Entrar.

vendedorvendedor123Puede crear clientes, ventas y servicios de taller. No puede eliminar.

Estas claves son de la página. Las de MySQL son otras y no se escriben en este formulario.

4. El menú

A la izquierda está el menú, en tres grupos:

  • Día a día: Inicio, Vehículos, Ventas, Clientes, Taller y Reporte.
  • Empresa: Sedes, Vendedores y Proveedores.
  • Control: Auditoría. Solo la ve el administrador.

Arriba a la derecha sale el nombre de quien entró y el botón Salir.

5. Inicio

Muestra cuánto se ha vendido, cuántos carros hay disponibles, cuántos vendidos, cuántos clientes y las últimas ventas. Con los datos que trae el proyecto se ven 18 carros disponibles, 2 vendidos, 20 clientes y un total de $150.000.000.

Esas dos ventas son de mayo de 2026: un Toyota Corolla en Medellín y un Nissan March en Cali.

6. Vehículos

Se puede filtrar por estado y por marca. El chasis es el número único del carro. En los datos de prueba empieza por CHS. La sede es Bogotá, Medellín o Cali.

El estado no se cambia a mano. Nace Disponible y pasa a Vendido cuando se registra la venta. Si se anula la venta, vuelve a Disponible.

Al agregar un carro se pide marca, modelo, año, precio, chasis y sede. Si después se cambia el precio, las ventas que ya se hicieron conservan el precio de ese día.

7. Ventas

En Agregar se elige el cliente, el vendedor, un carro que esté disponible y la forma de pago: Contado, Financiado o Tarjeta. El precio no se escribe. El sistema lo toma del carro.

Al guardar, el carro queda vendido. Solo el administrador puede anular una venta. El vendedor puede registrarlas, pero no borrarlas.

8. Clientes

Se ve el nombre, el apellido, la cédula, el teléfono y la dirección. El buscador sirve para apellido o cédula. La cédula no se puede repetir. El administrador y el vendedor pueden agregar y editar. Solo el administrador elimina.

9. Taller

Aquí se anota un servicio hecho a un carro. Se pide el carro, la fecha, qué se le hizo y cuánto costó. El cliente y el asesor pueden quedar vacíos. También se le puede hacer taller a un carro que ya se vendió.

10. Reporte

Se eligen dos fechas y se pulsa Consultar. Arriba sale el total de cada ciudad. Abajo salen las ventas que caen entre esas fechas.

Ojo: las ventas de prueba son del 10 y del 12 de mayo de 2026. Si el rango no incluye el 2026, el detalle sale vacío. Hay que dejar desde el 1 de enero de 2026 hasta el 31 de diciembre de 2026.

11. Sedes, vendedores y proveedores

Las sedes son Bogotá (Calle 100 # 15-30), Medellín (Carrera 43A # 1-50) y Cali (Avenida 6N # 25-40). Pedro Perez está en Bogotá, María Lopez en Medellín y Juan Ramirez en Cali. Los proveedores son las empresas que le venden los carros al concesionario. Estas tres pantallas solo las modifica el administrador.

12. Auditoría

Solo la ve el administrador. Cada venta nueva y cada venta anulada deja una fila. Las dos ventas que ya vienen cargadas no aparecen, porque se metieron antes de prender ese control. Para ver una fila hay que registrar una venta nueva.
