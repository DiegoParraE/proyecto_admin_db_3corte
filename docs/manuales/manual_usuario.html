Este manual explica cómo abrir el programa y qué hace cada pantalla. No hace falta conocer SQL para usarlo.

1. Qué hace el programa

El programa lleva el inventario, las ventas y el taller de un concesionario con tres sedes: Bogotá, Medellín y Cali. Cada carro tiene un chasis que no se repite. Cuando se vende, el sistema lo marca como vendido y ya no se puede vender otra vez.

2. Cómo abrirlo

  1. Abre Docker Desktop y espera a que diga que está en marcha.
  2. Abre la Terminal y escribe:
cd /Users/diego_parra/Desarrollos/proyecto_admin_db_3corte
docker compose up --build
  1. Cuando deje de salir texto nuevo, abre el navegador en http://localhost:8080.

No uses npm run dev ni yarn start. Este proyecto no es de Node. El comando correcto es docker compose up --build.

Para apagarlo, vuelve a la misma Terminal y pulsa Control + C. Si lo levantaste en segundo plano, usa docker compose down. Ese comando no borra los datos. docker compose down -v sí borra la base y la vuelve a crear vacía la próxima vez.

3. Entrar

En la pantalla de ingreso hay tres usuarios de prueba. Si pulsas uno, se llenan el usuario y la clave. Después pulsa Entrar.

UsuarioClaveQué puede hacer
adminadmin123Ver y cambiar todo. Es el único que ve Auditoría y el único que puede eliminar.
vendedorvendedor123Registrar clientes, ventas y servicios de taller. No elimina y no ve Auditoría.
consultaconsulta123Solo mirar. No aparece el botón Agregar.
Estas claves son del formulario. Las claves de MySQL son otras y no se escriben aquí. El manual técnico las explica.

4. Menú

A la izquierda hay tres grupos:

  • Día a día: Inicio, Vehículos, Ventas, Clientes, Taller y Reporte.
  • Empresa: Sedes, Vendedores y Proveedores.
  • Control: Auditoría. Solo la ve el administrador.

Arriba a la derecha está el nombre de quien entró y el botón Salir.

5. Inicio

Muestra el total vendido, cuántos carros están disponibles, cuántos vendidos, cuántos clientes hay y las últimas ventas. El botón Ver reporte abre el reporte de ventas.

Con los datos de prueba verás 18 carros disponibles, 2 vendidos, 20 clientes y un total de $150.000.000. Esas dos ventas son de mayo de 2026: un Toyota Corolla en Medellín y un Nissan March en Cali.

6. Vehículos

Lista los carros. Puedes filtrar por estado (Disponible o Vendido) y por marca.

  • Chasis: el número único de cada carro. En los datos de prueba empieza por CHS.
  • Sede: Bogotá, Medellín o Cali.
  • Estado: Disponible o Vendido. No se cambia a mano. Cambia solo cuando se registra o se anula una venta.

Agregar pide marca, modelo, año, precio, chasis y sede. El carro entra como Disponible. Editar permite corregir esos datos. Si cambias el precio, las ventas ya hechas conservan el precio del día en que se hicieron.

7. Ventas

Agregar abre Registrar venta. Eliges cliente, vendedor, un carro disponible y la forma de pago (Contado, Financiado o Tarjeta). El precio no se escribe: el sistema toma el precio del carro.

Al guardar, el carro pasa a Vendido y aparece en Inicio y en Auditoría. Eliminar, que solo tiene el administrador, anula la venta y el carro vuelve a Disponible.

El vendedor puede registrar ventas. No puede anularlas. Consulta solo puede ver la lista.

8. Clientes

Lista nombre, apellido, cédula, teléfono y dirección. El buscador acepta apellido o cédula. La cédula no se puede repetir. Admin y vendedor pueden agregar y editar. Solo admin puede eliminar.

9. Taller

Aquí se anotan los servicios hechos a un carro, esté vendido o no. Se pide el carro, la fecha, la descripción y el costo. El cliente y el asesor pueden quedar vacíos.

10. Reporte

Elige una fecha desde y una fecha hasta, y pulsa Consultar. Arriba aparece el total histórico de cada ciudad. Abajo, las ventas que caen dentro de esas fechas.

Las ventas de prueba son del 10 y del 12 de mayo de 2026. Si dejas el año en curso y no es 2026, el detalle sale vacío. Usa del 1 de enero de 2026 al 31 de diciembre de 2026.

11. Sedes, vendedores y proveedores

Sedes son las tres ciudades: Bogotá (Calle 100 # 15-30), Medellín (Carrera 43A # 1-50) y Cali (Avenida 6N # 25-40). Cada vendedor trabaja en una sede: Pedro Perez en Bogotá, María Lopez en Medellín y Juan Ramirez en Cali. Proveedores son las empresas que le venden los carros al concesionario. Solo el administrador crea, edita y elimina estas tres listas.

12. Auditoría

Solo la ve el administrador. Cada venta nueva y cada venta anulada deja una fila con la fecha, qué pasó y la cuenta de la base que lo hizo. Las dos ventas que vienen cargadas no aparecen, porque se insertaron antes de activar ese control. Registra una venta nueva para ver la primera fila.
